# briDge 

### Making Linux feel seamless for Windows switchers.

Transitioning from Windows to Linux often comes with a steep learning curve like navigating the terminal or configuring wine prefixes and tweaking configurations for hours. **briDge** builds straightforward, accessible tools to remove these barriers so that new users can just get things done asap.
